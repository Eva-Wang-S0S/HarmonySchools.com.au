# Assets Directory

Place your images, icons, and other static assets in this directory.

## Suggested Structure
```
assets/
├── images/
│   ├── profile.jpg
│   └── projects/
├── icons/
│   └── favicon.ico
└── documents/
    └── resume.pdf
```

## Usage

Reference assets in your HTML using relative paths:
- `<img src="assets/images/profile.jpg" alt="Description">`
- `<link rel="icon" href="assets/icons/favicon.ico">`
